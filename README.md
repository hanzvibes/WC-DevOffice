# WC Dev Office

Game-like realtime development visualization for Wedding Copilot.

## MVP
- Vercel-hosted office UI
- Worker states: IDLE / READING / CODING / TESTING / REVIEWING / BLOCKED / DONE
- Event bridge planned for Codex structured events
- GitHub/Vercel milestones remain permanent project events

## Local
\`npm install\`
\`npm run dev\`

This repository is intentionally separate from Wedding Copilot production code.
